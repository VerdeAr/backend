# Verdear — Backend

API do sistema **Verdear**, marketplace de produtos orgânicos e da agricultura familiar, consumida pelo repositório [`frontend`](https://github.com/VerdeAr/frontend).

Este repositório substitui a camada de backend do monolito legado [`Verdear`](https://github.com/VerdeAr/Verdear), que segue ativo em paralelo durante a migração.
